# پنل ادمین — برش اول پیاده‌سازی

تاریخ: ۲۰۲۶/۱۰/۱۲. این سند وضعیت کد همین برش را ثبت می‌کند. دامنهٔ کامل محصول در [طرح اجرایی](blueprint.md) و تسک‌های باقی‌مانده در [backlog](backlog.md) حفظ شده‌اند.

## صفحات متصل

همهٔ صفحات از پوستهٔ حساب، theme و kit فعلی استفاده می‌کنند؛ فارسی، RTL، تاریخ نمایشی شمسی با منطقهٔ زمانی تهران، حالت بارگذاری، خطا و فهرست خالی دارند. اطلاعات از API خوانده می‌شوند.

| مسیر                                                | قابلیت                                                                                      |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `/`                                                 | شمار کاربران، مجموعه‌ها، بررسی‌های منتظر، انتشارها، نظرهای منتظر و پنج رویداد اخیر          |
| `/users`                                            | جست‌وجوی نام/موبایل، فیلتر وضعیت، صفحه‌بندی، تغییر وضعیت با دلیل                            |
| `/users/:userId`                                    | حساب، همکاری‌ها، معرفی مربی، ۲۵ نشست اخیر بدون اطلاعات محرمانه و اقدام‌های کاربر            |
| `/organizations`                                    | جست‌وجو، وضعیت تأیید و انتشار، پرونده و تصمیم همراه دلیل                                    |
| `/organizations/:organizationId`                    | معرفی، مالک، تماس، دسته‌بندی، رسانه، آمادگی انتشار، شعبه‌ها، تیم و سابقه مجموعه             |
| `/organizations/:organizationId/branches/:branchId` | نشانی، مخاطبان، ساعات/استثناها، قوانین، فضاها، امکانات، تجهیزات، مربیان و گالری             |
| `/catalog-reviews`                                  | صف پروفایل‌های ارسال‌شده برای بررسی انتشار و ورود به پرونده                                 |
| `/taxonomies`                                       | شش گروه نوع مجموعه، رشته، تجهیزات، امکانات، برچسب و دسترس‌پذیری؛ افزودن/ویرایش/غیرفعال‌سازی |
| `/locations`                                        | فهرست وابستهٔ کشور، استان، شهر و منطقه؛ ایجاد و ویرایش نام                                  |
| `/moderation`                                       | فهرست نظرهای منتظر، منتشرشده و ردشده؛ تصمیم با دلیل و کنترل تغییر وضعیت هم‌زمان             |
| `/audit`                                            | سابقه تغییرناپذیر با فیلتر نوع رویداد و بازهٔ تاریخ؛ نام عامل و مجموعه                      |
| `/login`, `/profile`, `/sessions`, `/invitations`   | صفحات موجود ورود و حساب حفظ شده‌اند                                                         |

## سرویس‌ها

پیشوند مشترک `/api/v1` است. مسیرهای مدیریتی به نشست `admin` و رکورد `platformAdmins` نیاز دارند. انتخاب کلاینت یا مخفی‌بودن منو، مجوز ایجاد نمی‌کند.

| API                                       | قرارداد                                                            |
| ----------------------------------------- | ------------------------------------------------------------------ |
| `GET /admin/overview`                     | شمارش واقعی و رویدادهای اخیر                                       |
| `GET /admin/users`                        | `page`, `search`, `status`؛ حداکثر ۲۵ ردیف                         |
| `GET /admin/users/:id`                    | پرونده؛ توکن و هش نشست در پاسخ وجود ندارد                          |
| `PATCH /admin/users/:id/status`           | وضعیت و دلیل؛ تعلیق نشست‌ها را لغو می‌کند؛ تعلیق ادمین مجاز نیست   |
| `GET /admin/organizations`                | `page`, `search`, `status`, `publicationStatus`؛ حداکثر ۲۵ ردیف    |
| `GET /admin/organizations/:id`            | مجموعه، اعضا، شعبه‌ها و وجود پروفایل کاتالوگ                       |
| `POST /admin/organizations/:id/review`    | تأیید، رد یا تعلیق همراه دلیل                                      |
| `GET /admin/clubs/:id`                    | پرونده کاتالوگ برای ادمین                                          |
| `GET /admin/clubs/:id/readiness`          | نتیجهٔ کامل‌بودن اطلاعات و خطاهای هر فیلد                          |
| `GET /admin/clubs/:id/branches/:branchId` | فقط شعبه متعلق به همان مجموعه                                      |
| `POST /admin/clubs/:id/review`            | مسیر موجود تصمیم درباره باشگاه                                     |
| `GET/POST /admin/taxonomies/:kind`        | جست‌وجو و صفحه‌بندی ۱۰۰ ردیفی، ایجاد                               |
| `PATCH /admin/taxonomies/:kind/:id`       | ویرایش؛ غیرفعال‌ها در انتخاب عمومی نمی‌آیند                        |
| `GET /admin/locations/:kind`              | `parentId` برای سطح‌های پایین‌تر لازم است                          |
| `POST /admin/locations`                   | ایجاد با `kind`, `name` و کد کشور یا والد                          |
| `PATCH /admin/locations/:kind/:id`        | فقط ویرایش نام؛ انتقال والد و تغییر کد کشور از این مسیر مجاز نیست  |
| `GET /admin/reviews`                      | `page`, `status`؛ حداکثر ۲۵ ردیف، نام نویسنده و شعبه               |
| `POST /admin/reviews/:id/moderate`        | `status`, `reason`, `expectedStatus`؛ تصمیم منسوخ پاسخ ۴۰۹ می‌گیرد |
| `GET /admin/audit`                        | `page`, `action`, `actorId`, `organizationId`, `from`, `to`        |

تاریخ‌های ورودی فیلتر API از نوع ISO میلادی هستند. انتهای بازهٔ audit تا پایان روز محلی تهران محاسبه می‌شود. ورودی نامعتبر، ترتیب معکوس تاریخ‌ها، ارجاع ناموجود و برخورد شناسه‌ها پاسخ خطای مناسب دارند. علامت‌های `%` و `_` در جست‌وجو به‌صورت کاراکتر واقعی تفسیر می‌شوند.

## قواعد اجرایی

- تأیید مجموعه و انتشار مستقل‌اند. پس از تأیید، مالک باید اطلاعات ضروری را کامل و انتشار را درخواست کند؛ ادمین با تأیید یک مجموعه ناقص آن را عمومی نمی‌کند.
- تعلیق مجموعه نمایش عمومی را پنهان می‌کند. تغییر وضعیت کاربر، تصمیم بررسی، ویرایش دسته‌بندی و ایجاد/ویرایش جغرافیا سابقه دارند.
- تصمیم درباره نظر داخل تراکنش و با قفل رکورد انجام می‌شود. UI وضعیت مشاهده‌شده را ارسال می‌کند؛ نسخهٔ قدیمی تصمیم، تصمیم جدید را بازنویسی نمی‌کند.
- دسترسی ادمین فعلاً سطح پلتفرم دارد. نقش‌های تفکیک‌شدهٔ پشتیبانی، مالی و محتوا در این برش ساخته نشده‌اند.
- صفحات ادمین `noindex` هستند؛ این تنظیم جایگزین کنترل دسترسی نیست.

## اعتبارسنجی

- ۲۳ تست یکپارچهٔ کاتالوگ/ادمین با PostgreSQL مستقل `_test`: دسترسی مجاز/غیرمجاز، عدم نشت اطلاعات نشست، تعلق شعبه، جست‌وجو، جغرافیا، دسته‌بندی، audit و تعارض تصمیم نظر.
- ۱۸ تست یکپارچهٔ ورود و پنل‌های موجود؛ ۲۰ تست واحد API.
- TypeScript و lint در API، UI و ادمین؛ بیلد ادمین با Webpack.
- بررسی مرورگر با API و دادهٔ آزمایشی مستقل: صفحه‌های متصل، ایجاد/ویرایش دسته‌بندی، ایجاد کشور، بررسی نظر و عرض‌های دسکتاپ/موبایل.

مسیر Webpack نیز با همان loader نصب‌شدهٔ Tailwind پردازش CSS دارد. در محیط محدود این اجرا، Turbopack در ساخت پردازش CSS به خطای مجوز پورت داخلی رسید؛ تنظیم پیش‌فرض Turbopack حفظ شده و Webpack مسیر جایگزین بررسی است. workflow تصویری 12ui به‌دلیل نبود مرورگر بستهٔ خودش اجرا نشد؛ ظاهر با kit موجود و بررسی تصویری Chrome ارزیابی شد.

## دامنهٔ باقی‌مانده

مالی، پرداخت/استرداد/تسویه، پرونده پشتیبانی، مدارک مربی، اعلان و کمپین، دستگاه‌ها، صف job، feature flags، نقش‌های تفکیک‌شدهٔ ادمین و گزارش‌های تجاری به مدل و سرویس‌های فازهای بعد وابسته‌اند. اصالت نظر بر مبنای حضور نیز هنوز مدل حضور/رزرو را ندارد؛ نمایش نظر به معنای تأیید حضور نیست. این برش والدهای T017، T025 و T065 یا کل M16 را کامل نمی‌کند.
