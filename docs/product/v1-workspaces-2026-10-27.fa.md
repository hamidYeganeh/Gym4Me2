## سابقه و تعهدهای قبلی

خرید تازهٔ برنامهٔ غیرحضوری در فهرست، جزئیات عمومی، پیش‌فاکتور، checkout و ساخت خدمت عمومی بسته است. سفارش قبلی همچنان می‌تواند تسویه، پیگیری یا مسترد شود. برنامهٔ تحویل‌شده در «برنامه‌های قبلی من» خوانده و به PDF تبدیل می‌شود؛ این صفحه ابزار ثبت تمرین ندارد.

برای تعهدهای پرداخت‌شدهٔ قبلی، API محدود برنامه فقط مربی همان درخواست، رابطهٔ همان ورزشکار، سفارش پرداخت‌شده و وضعیت در انتظار تحویل/اصلاح را می‌پذیرد؛ مجوز در تراکنش نیز بازبینی می‌شود. ابزار عمومی ساخت برنامه برنمی‌گردد. رابط سابق سفارش، اطلاعات اولیه، انتخاب نسخهٔ موجود و پیگیری اصلاح را حفظ می‌کند. آماده‌سازی نسخهٔ تازه برای تعهدهای قدیمی از API محدود انجام می‌شود.

جدول‌ها، نسخه‌های تاریخی، خروجی و حذف حساب، فایل‌ها، دفتر مالی و استردادها حفظ شده‌اند. سرویس‌های داخلی لازم برای سازگاری و آزمون داده‌های قدیمی باقی‌اند و مسیر عمومی فضای تمرین/دعوت را فعال نمی‌کنند. worker قدیمی تمرین فقط cache مربوط به خودش را پاک و ثبت خود را لغو می‌کند؛ worker اعلان و دادهٔ حساب‌های دیگر دست‌کاری نمی‌شود.
