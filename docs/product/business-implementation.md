# برش فعلی پنل بیزینس

پنل بیزینس از دیزاین سیستم موجود و پکیج‌های مشترک `@repo/api` و `@repo/i18n` استفاده می‌کند. اطلاعات از API و PostgreSQL خوانده و ذخیره می‌شوند. دادهٔ نمونهٔ Discovery هنوز مستقل است.

| مسیر                                                | قابلیت                                                                                                                                                                    |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/`                                                 | نمای کلی مجموعه‌ها و وضعیت بررسی                                                                                                                                          |
| `/organizations`                                    | ایجاد مجموعه، نقش کاربر، وضعیت بررسی و لینک مدیریت باشگاه                                                                                                                 |
| `/organizations/:organizationId`                    | معرفی کوتاه/کامل، نام و شناسه، دسته‌بندی، ورزش، برچسب و تماس؛ ثبت لینک تصویر، گالری و کاور؛ شعبه‌ها؛ چک‌لیست آمادگی و ارسال برای بررسی/انتشار/پنهان کردن                  |
| `/organizations/:organizationId/branches/:branchId` | نام و وضعیت فعالیت، تماس و قوانین مراجعه، نشانی و سلسله‌مراتب کشور/استان/شهر/منطقه و مختصات، ورزش/تجهیزات/امکانات/دسترس‌پذیری، مخاطبان و چند بازهٔ هفتگی با پایان روز بعد |
| `/branches?organization=:id`                        | انتخاب مجموعه و افزودن شعبه                                                                                                                                               |
| `/team`                                             | دعوت همکار، مشاهده تیم و لغو دسترسی/دعوت توسط مالک                                                                                                                        |
| `/profile`، `/sessions`، `/invitations`             | پروفایل، نشست‌ها و پذیرش دعوت تیم                                                                                                                                         |

مالک و مدیر می‌توانند مشخصات باشگاه و شعبه را ویرایش کنند؛ پذیرش و حسابداری فقط این اطلاعات را مشاهده می‌کنند. API همین مجوزها را مستقل از رابط اعمال می‌کند. ایجاد مجموعه یک باشگاه و شعبهٔ اصلی می‌سازد. ساعت هفتگی با قرارداد شنبه ۰ تا جمعه ۶ ذخیره می‌شود. خطاها و متن‌های رابط فارسی و انگلیسی در کاتالوگ ترجمه نگهداری می‌شوند.

ذخیرهٔ تغییرات، آمادگی انتشار و فهرست‌های مرتبط را از طریق TanStack Query به‌روز می‌کند. تغییر اطلاعات منتشرشده وضعیت را به پیش‌نویس برمی‌گرداند و صفحه تا بررسی دوباره از کاتالوگ عمومی خارج می‌شود. انتشار فقط پس از تکمیل اطلاعات لازم و تأیید ادمین مجاز است. ارسال نامعتبر، خطاهای فیلدها را نمایش می‌دهد و متن واردشده در فرم باقی می‌ماند.

این برش شامل آپلود فایل، ویرایش شبکه‌های اجتماعی، جزئیات تعداد/هزینهٔ تجهیزات و امکانات، ویرایش استثناهای تقویم، فضاها و مربیان شعبه، پاسخ به نظرها، رزرو، تسویه یا پرداخت نیست. قراردادهای API موجود این حوزه‌ها در پکیج API قرار دارند؛ ساخت رابط این قابلیت‌ها در گام‌های بعدی باقی است. فرم شعبه استثناهای ساعات و جزئیات قبلی امکانات/تجهیزات و سیاست سن را هنگام ذخیره حفظ می‌کند.

برای اجرای محلی: API روی 7088، business روی 7083 و admin روی 7082. تغییر آدرس API نیاز به تنظیم `API_URL` هنگام build دارد. دستورهای بررسی در [پکیج API](../../packages/api/README.md) آمده‌اند؛ تست‌های HTTP در [clubs.integration-spec.ts](../../apps/api/test/clubs.integration-spec.ts) قرارداد دسترسی و انتشار و ترجمه را پوشش می‌دهند.
