- ۱۰۱ تست واحد API در ۱۷ مجموعه موفق؛ ساخت تایپ و ESLint فایل‌های تغییرکرده موفق.
- ۵ تست مسیرهای بومی و تطبیق ثبت Android/iOS موفق؛ ۲ تست هم‌ارزی ترجمه‌ها و بررسی کپی موفق.
- [CI نسخهٔ نهایی](https://github.com/hamidYeganeh/Gym4Me2/actions/runs/40077902711): هر دو job اندروید/وب/API و ساخت iOS موفق شدند؛ پذیرش واحد/یکپارچه، ظرفیت، مبلغ، صف و تکرار فرمان همگی سبز هستند. آزمون جدید دیتابیس شامل امضای نامعتبر، رسید تکراری، callback تکراری و لغو بدون رسید است.
- بررسی فقط‌خواندنی کاوه‌نگار: کلید معتبر، حساب دارای اعتبار، `gym4meotp` تأییدشده، debug غیرفعال. نشست مصنوعی وب و بومی در API منتشرشده معتبر بود؛ پیامکی برای آزمون ارسال نشد.
- آزمایش قرارداد BankTest با ۱۰٬۰۰۰ ریال کاملاً شبیه‌سازی‌شده: توکن، صفحهٔ بانک، Verify و Reverse موفق. این آزمایش اولیه به سفارش برنامه متصل نبود.

## حدود پذیرش

حساب آزمایشی سفارش، شمارهٔ ساختگیِ غیرقابل ارسال و نشست کوتاه‌مدت جداگانه دارد. هیچ حساب واقعی جعل یا تغییر نکرد و هیچ مجوز مدیریتی برای آن ایجاد نشد. اطلاعات کارت callback ذخیره نمی‌شوند. شواهد خصوصی و توکن‌ها فقط در `.artifacts/sms-saman/` نادیده‌گرفته‌شده توسط Git قرار دارند.

بانک تست شبیه‌ساز مستقل است؛ پرداخت واقعی سامان و برداشت وجه واقعی فعال نیست. در بررسی اولیهٔ پیش از خرید، پذیرنده اعتبار زمانی فعال نداشت. پس از خرید کاربر، وضعیت فعال تا ۱۴۰۵/۰۹/۰۲ در پنل مشاهده و پرداخت تازه با برگشت کامل تأیید شد؛ [گزارش آزمون پس از خرید](banktest-activation-2026-10-24.md). بازپرداخت جزئی یا سفارش دارای چند رسید نیازمند بررسی می‌ماند. دریافت پیامک روی گوشی و رفت‌وبرگشت مرورگر روی دستگاه فیزیکی هنوز تأیید نشده‌اند.
