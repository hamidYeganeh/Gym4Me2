# PH0 — دادهٔ عمومی و نگاشت مسیرها

پذیرش PH0 همچنان باز است. این برش زیرساخت دادهٔ ثابت برای بررسی پیوستهٔ صفحات عمومی، نگاشت قابل بررسی هر۹۶ ورودی صفحه و اصلاح حرکت Sheet ورود را اضافه می‌کند. هیچ ردیف پذیرش با این گزارش بسته نمی‌شود.

## تغییر کد

سناریوی محلی `ph0-public` در fixture موجود، کاتالوگ باشگاه، شعبه، خدمات، تقویم و سیاست داده را هم‌زمان ارائه می‌کند. شناسهٔ سازمان/شعبه و نام‌ها در خدمات و تقویم با اولین باشگاه نمایشی هماهنگ‌اند؛ بنابراین رفتن از باشگاه به خدمات شعبه و از تقویم به جزئیات خدمت، دادهٔ مرتبط دارد. این محتوا مصنوعی است؛ دادهٔ کاربر یا seed تولید نیست. GET حساب، session و تقویم‌های دنبال‌شده۴۰۱ می‌ماند؛ متدهای نوشتن۴۰۵ و بدون cookie هستند. سناریوهای خطا/خالی/کند قبلی حفظ شدند.

[تست قرارداد](../../apps/application/test/web-read-fixture.test.ts) اتصال باشگاه/شعبه/خدمات/تقویم، سیاست داده، رد دسترسی حساب و متدهای نوشتن را بررسی می‌کند. آزمون‌های fixture به‌تنهایی ورود، مجوزهای API واقعی یا رفتار مرورگر را ثابت نمی‌کنند.

## نگاشت منبع

[جدول۹۶ مسیر](ph0-route-contracts-2026-10-18.md) و [گراف کامل](ph0-route-contracts-2026-10-18.json) از exportهای واقعی صفحه تولید شده‌اند:۵۲ application،۲۴ business و۲۰ admin. گراف re-exportهای مؤلفه‌ها را دنبال می‌کند؛ برای هر صفحه، نمادهای وابسته، layoutهای والد، عبارت فراخوانی hook، خط تعریف API، شرط‌های منتخب حالت و آزمون‌هایی که مستقیماً منبع مرتبط را import می‌کنند ثبت می‌شود.

۲۳۶ محل یکتای فراخوانی API شناسایی شد.۹۰ صفحه در وابستگی‌های بالقوهٔ خود فراخوانی API دارند. برای نمونه، `/calendars` از re-export `community` فقط به `useSportsCalendars` می‌رسد؛ API جزئیات یا پشتیبانی به این صفحه نسبت داده نشده است. `/services` به پرس‌وجوی `sports/services` و `/login` به سه hook ورود می‌رسد. تعریف تمام hookهای ثبت‌شده و export ورودی تمام صفحات resolve شد؛ hash۴۰۰ فایل در لحظهٔ بررسی نهایی تطبیق داشت. رسید بررسی در `.artifacts/ph0-zoom-2026-10-18/graph-integrity.json` است؛ این، تضمین ثبات بعدی درخت کاری نیست.

این گراف تحلیل معنایی TypeScript نیست. نام‌های هم‌نام می‌توانند وابستگی اضافی بسازند و propهای workspace مشترک فقط زیرمجموعه‌ای از شاخه‌ها را اجرا کنند. ارتباط import یک آزمون، پوشش assertion یا تازه‌بودن اجرای آن نیست. endpointهای ساخته‌شده داخل hook، حالت‌های API، providerها و رفتار واقعی هر مسیر همچنان به بررسی جدا نیاز دارند. این خروجی جای نگاشت نهایی «صفحه ← API ← حالت اجراشده ← آزمون/شاهد» را نمی‌گیرد؛ محل‌های بررسی آن را مشخص می‌کند.

## بررسی‌های اجراشده

- هر۱۱۵ تست `apps/application/test/*.test.ts` با concurrency۱ و heap۱۹۲MiB پاس شد؛ شامل۳۱ تست fixture و۶ تست اعتبارسنجی ورود. log: `.artifacts/ph0-zoom-2026-10-18/all-tests.txt`. adapterهای native در این مجموعه mock هستند و دستگاهی اجرا نشده است.
- typecheck نهایی application با heap۶۴۰MiB پاس شد؛ log: `.artifacts/ph0-zoom-2026-10-18/typecheck-final.txt`.
- lint سه فایل fixture/تست/launcher، syntax اسکریپت گراف، بررسی خطای whitespace و محافظ۵۹ فایل پاس شد.
- پیش‌نمایش اولیه از build قبلی application با شناسهٔ `IJN-zDWQ0RoE3kssUZifg` استفاده کرد. تطبیق پایانی مشخص کرد۷ hash رسید قبلی با منبع فعلی متفاوت است و فایل‌ها پس از build قبلی تغییر کرده‌اند: Luma CSS، auth CSS، سه فایل فرم ورود و دو ترجمه. گزارش تفاوت در `.artifacts/ph0-zoom-2026-10-18/previous-source-mismatches.json` ثبت است. بنابراین تصاویر/فوکوس/کنتراست قبلی، پذیرش این نسخهٔ فعلی را ثابت نمی‌کنند؛ باید روی build تازه دوباره مشاهده شوند. هیچ فایل تغییرکرده‌ای برای تطبیق با رسید قدیمی بازگردانده نشد.
- سه build تازهٔ application/business/admin کامپایل، typecheck و تولید صفحات را گذراندند. log و شناسه‌ها در `.artifacts/ph0-zoom-2026-10-18/builds.json` ثبت‌اند. شروع اول admin چند ثانیه با trace انتهایی business هم‌پوشانی داشت؛ فوراً متوقف شد و پس از خروج business جدا اجرا شد. heap۶۴۰MiB و worker۱ بود. این سقف V8 است، نه سقف کل RAM.
- در همین بازه، تقویم، QueryError، login و auth CSS هم‌زمان تغییر کردند. snapshot۶۵۴ ورودی منتخب و تفاوت‌های بعدی ثبت است. در نتیجه هیچ ادعای همسان‌بودن تمام buildها با درخت کاری فعلی نداریم. تست۱۱۵تایی و typecheck مستقل نیز پیش از آخرین این ویرایش‌ها اجرا شدند؛ شاهد همان برش هستند.

## اصلاح و مشاهدهٔ Sheet ورود

در CSS محدوده‌دار account، مدت Sheet ورود از۴۵۰ به۳۲۰ms تغییر کرد؛ transition نیز۳۲۰ms شد. reduced-motion، animation/transition و backdrop blur Sheet و تغییر مقیاس دکمهٔ active را حذف می‌کند. اجزای محافظت‌شده دست‌نخورده‌اند.

کنترل مرورگر بعداً بازیابی شد. [رسید مرورگر](ph0-auth-sheet-2026-10-18.json) فقط build application با شناسهٔ `iMjpby3x5nuJ76wBVFbOB` را پوشش می‌دهد: فارسی، عرض۳۶۰/ارتفاع۸۴۴ و DPR۲، دو تم و حرکت عادی/reduce. در چهار نمونه، کنترل‌ها حداقل۴۴px بودند، فوکوس داخل dialog و سرریز افقی false بود. حالت عادی duration محاسبه‌شدهٔ۰٫۳۲s داشت؛ این، اندازه‌گیری کامل خط زمانی نیست. reduce، animation/transition۰ و backdrop/transform none داشت. تغییر media در حالی که transform برابر۳٫۷۶۹۴px مشاهده شده بود، transform/animation را none کرد. چهار Tab در dialog چرخیدند؛ Escape و Back ابتدا Sheet را بستند، مسیر `/` ماند و فوکوس به دکمهٔ آغاز برگشت.

[PNG](baselines/ph0-public-contracts-2026-10-18/auth-sheet-fa-dark-reduce.png) با backing مطابق DPR و دو فریم متوالی یکسان ثبت و دیده شد؛ [رسید capture](ph0-auth-sheet-capture-2026-10-18.json). blur در این نمونه حذف است؛ پس‌زمینهٔ نیمه‌شفاف هنوز محتوای زیرین را نشان می‌دهد. پذیرش کنتراست کامل از این تصویر نتیجه نمی‌شود. auth CSS و login دوباره در حین این بازه تغییر کردند؛ رسید build را به hash فعلی نسبت نمی‌دهیم. رفتار فعلی باید پس از ثبات کد دوباره بررسی شود. انگلیسی، صفحه‌خوان، دستگاه، zoom واقعی و تمام خانواده‌های Sheet در این برش آزموده نشدند.

## مرورگر و پاک‌سازی

صفحهٔ خانهٔ قدیمی با دادهٔ ترکیبی در تب اختصاصی Chrome باز شد و پنج خدمت مرتبط با باشگاه نمایشی در درخت دسترس‌پذیری دیده شد. این مشاهده، QA بصری یا reflow محسوب نمی‌شود. انتخاب تب برای آزمون zoom با پیام مشغول‌بودن Chrome به تعامل کاربر متوقف شد. سپس بستن تب/ساخت تب پس‌زمینه و inventory timeout شدند. inventory بازیابی‌شده تب Chrome متعلق به این کار را نشان نمی‌داد و تب پس‌زمینهٔ ساخته‌شده را نشان داد. همان تب برای آزمون Sheet استفاده و در پایان صریحاً بسته شد. media/metrics/viewport موقت آن پاک شدند. زوم واقعی۲۰۰٪ آزموده نشده است؛ viewport۳۶۰ شاهد zoom نیست.

پیش‌نمایش Next و fixture متعلق به این برش متوقف شدند؛ handleها خروج۱۳۰ و۰ گزارش کردند. آزمون‌ها نیز تمام شدند. دیتابیس، Docker، Android، iOS و سرویس خارجی اجرا نشدند.

ادامهٔ پذیرش به QA واقعی مرورگر برای کارت/نقشه/جزئیات، حرکت/Back/Sheet/اسکرول، حالت‌های کند/آفلاین/تم، دسترس‌پذیری/zoom/reader و شاهد دستگاه نیاز دارد. نبود شاهد را موفقیت تلقی نمی‌کنیم.
