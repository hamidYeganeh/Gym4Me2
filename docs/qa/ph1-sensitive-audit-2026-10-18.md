# ثبت عملیات حساس PH1 — ۱۸ اکتبر ۲۰۲۶

T025 در محدودهٔ قیمت و دسترسی PH1 پذیرفته شد. پذیرش کامل PH0/PH1 باز است.

## تغییر

دعوت تیم، قطع عضویت، لغو دعوت، نسخهٔ تازهٔ تعرفه و فعال/غیرفعال‌کردن تعرفه اکنون دلیل انسانی ۳ تا ۵۰۰ نویسه، پس از trim، می‌خواهند. API، DTO، کلاینت و فرم‌های موجود هماهنگ‌اند. دلیل در جدول audit نگهداری می‌شود و به نسخه/شرایط عمومی تعرفه اضافه نمی‌شود. ایجاد اولیهٔ تعرفه reasonCode دارد؛ تغییر بعدی دلیل انسانی دارد.

سابقهٔ دعوت actor، زمان، مجموعه، مرجع دعوت، نقش و محدوده را دارد. هنگام قطع دسترسی، نقش و شعبه‌های قبل از حذف و نتیجهٔ قطع دسترسی ذخیره می‌شوند؛ حذف grantها سابقه را از بین نمی‌برد. پذیرش دعوت به شناسهٔ دعوت، نقش، محدوده و reasonCode متصل است. سابقهٔ قیمت، شناسهٔ نسخهٔ قبلی/بعدی، قیمت قبلی/بعدی و شعبه را نگه می‌دارد. وضعیت تعرفه مقدار قبلی/بعدی را دارد.

دستور bootstrap ادمین هم دلیل اجباری و هویت کاربر سیستم‌عامل، actorKind=operator و scope=platform ثبت می‌کند. actorId برای اپراتور بیرون برنامه null است؛ حساب مقصد به‌عنوان عامل جعل نمی‌شود. تکرار grant، رویداد اضافی نمی‌سازد. اجرای واقعی این دستور فقط روی حساب مصنوعی دیتابیس آزمون انجام شد.

## شاهد اجرا

همهٔ کدنویسی پیش از اجرای پروژه انجام شد. آزمون‌ها ترتیبی، با PostgreSQL آزمون روی۵۵۴۳۳ و bucket موقت S3 اجرا شدند. پایگاه مستقل `gym4me_ph1audit_1a14f2c8_test` ساخته شد؛ پایگاه‌های قبلی دست‌نخورده ماندند.

| واحد API | ۲۶ پاس، شامل جلوگیری از چاپ SQL/شماره/token/دلیل در exception عمومی |

دلیل absent، خالی، دو نویسه و۵۰۱ نویسه برای ویرایش قیمت/وضعیت رد شد؛ نسخه/قیمت قبلی ثابت ماند. قطع عضویت بدون دلیل انجام نشد؛ پس از قطع معتبر، همان حساب دسترسی شعبه را از دست داد. شش رویداد حساس موفق با actor/time/target/reason و محدودهٔ مورد انتظار تطبیق داده شدند. تاریخچه و DTO تعرفه دلیل را افشا نکردند؛ مسیر audit برای بیزینس403 است. بررسی منبع loggerهای API نیز پیام‌های عمومی ثابت و آمار نگهداری را نشان داد؛ نتیجه به این مسیرهای PH1 محدود است، نه ممیزی امنیتی تمام محصول.

build بیزینس `Qb1ATcqUJSRSUaU7LZeNH` با یک worker و heap640MiB پاس شد.۵۱۰ ورودی منبع در شروع، پایان build و پس از تست مرورگر ثابت بودند. TypeScript API و UI، lint فایل‌های تغییرکرده، copy، محافظ۵۹ فایل و diff-check پاس شدند.

## مرورگر واقعی روی API محلی

روی همان build، مالک مصنوعی وارد شد و دعوت همراه دلیل ثبت کرد؛ دعوت از دیالوگ همراه دلیل لغو شد. تعرفهٔ۲۰۰٬۰۰۰ تومانی با دلیل به نسخه۲ و۲۲۵٬۰۰۰ تومان تغییر کرد؛ سپس با دلیل غیرفعال شد. چهار رویداد همین عملیات از DB خوانده شدند و actor، مجموعه، مرجع، زمان، دلیل و تغییرات قبلی/بعدی تطبیق داده شدند. UI قطع عضویت در این برش دوباره اجرا نشد؛ قرارداد و قطع دسترسی آن در آزمون API پوشش دارد.

در هر چهار فرم دعوت/لغو/ویرایش قیمت/وضعیت، ارسال دلیل خالی صفر POST داشت؛ buffer شبکه کامل و بدون truncated/hasMore بود. focus روی reason با aria-invalid=true قرار گرفت. لغو موفق دیالوگ را بست و focus به شمارهٔ دعوت برگشت؛ ذخیرهٔ قیمت و وضعیت focus را به دکمهٔ آغازگر برگرداند.

چهار حالت فارسی/انگلیسی × روشن/تیره در viewport واقعی۳۶۰×۷۸۰، روی فرم خطای وضعیت بررسی شدند: label یکتا، hint/error متصل، aria-required، RTL/LTR صحیح، textarea با ارتفاع۹۶ و دکمه‌های۴۴ پیکسل، بدون شناسهٔ تکراری یا سرریز افقی سند. این شاهد دستگاه، zoom۲۰۰٪، صفحه‌خوان یا پذیرش همهٔ فرم‌های PH0 نیست.

## محدودیت و پاک‌سازی

سقف اولیهٔ۳۸۴MiB برای بررسی کامل UI کافی نبود؛ همان بررسی با۷۶۸MiB و بدون کار سنگین هم‌زمان پاس شد. اجرای sandbox برای bind محلی EPERM داد؛ آزمون‌های شبکه با اجرای مجاز تکرار شدند. یک نمونهٔ آزمون حداقل طول اشتباهاً واژهٔ دونویسه‌ای را معتبر فرض می‌کرد؛ اصلاح شد و همهٔ۱۳۵ آزمون وب/کلاینت دوباره پاس شدند. این شکست‌های اولیه به‌عنوان پاس شمرده نشده‌اند.

آثار محلی در `.artifacts/ph1-audit-2026-10-18/` شامل log آزمون‌ها، receipt منبع/build، `browser-observations.json` و `runtime-audit.json` هستند. پوشهٔ حاوی دادهٔ مصنوعی مجوز۷۰۰ دارد. پس از خروج UI، cookie زبان، media و viewport بازگردانده و تب بسته شد؛ preview با exit130 و fixture با exit0 متوقف شدند؛ پایگاه موقت DROP شد. containerهای موجود متوقف یا بازپیکربندی نشدند. پیامک زنده و انتشار بیرونی انجام نشد.

پذیرش کامل [PH0](ph0-acceptance.md)، دستگاه/native، نشست‌ها، کاتالوگ واقعی وب/native، CI و عملیات انتشار/بازیابی مستقل همچنان بازند. کاربر فعلاً مقصد بکاپ خارج از مک ندارد. تصمیم جدید کاربر دربارهٔ زمان حرکت‌ها در معیار PH0 ثبت شد:۱۲۰/۲۲۰/۲۰۰ms؛ تاریخچهٔ شاهدهای قدیمی بازنویسی نشد.
