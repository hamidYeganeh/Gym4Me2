# Baselineهای دیداری محافظت‌شده

نمونهٔ واقعی صفحه جزئیات باشگاه آفتاب با دادهٔ UI fixture، در ۱۵ اکتبر ۲۰۲۶، مرورگر ۱۲۸۰×۷۲۰:

- [فارسی، تیره](club-detail-fa-dark-desktop.jpg)
- [فارسی، روشن](club-detail-fa-light-desktop.jpg)

هر دو تصویر بعد از بارگذاری و بازبینی ذخیره شدند؛ تصویر اولیهٔ سفیدِ هنگام بارگذاری رد و جایگزین شد. زبان و تم مرورگر پس از capture به فارسی و تیره بازگردانده شد. این دو تصویر فقط نمای بالای صفحهٔ جزئیات هستند. baseline همهٔ انواع کارت، انگلیسی و عرض‌های موبایل هنوز کامل نشده و نباید به‌عنوان پذیرش پیکسلی PH0 گزارش شود.
