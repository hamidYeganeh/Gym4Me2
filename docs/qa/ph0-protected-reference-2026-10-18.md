# reference تصویری جزئیات محافظت‌شده — ۱۸ اکتبر ۲۰۲۶

مرحلهٔ اول P0-01 از [پذیرش PH0](ph0-acceptance.md). دوازده تصویر تمام‌صفحه از **همان ClubPage و ClubDetail فعلی** در فارسی/انگلیسی، روشن/تیره و۳۶۰/۳۹۰/۴۳۰ ثبت شدند. این‌ها reference پیش از تغییرات بعدی PH0 هستند؛ مقایسهٔ قبل/بعد و پذیرش کامل تمام کارت‌ها هنوز انجام نشده است. دو baseline قدیمی دسکتاپ دست‌نخورده‌اند.

دادهٔ ثابتِ `protected-catalog` شامل دو باشگاه مصنوعی و شعبه‌های مربوط، تصویر محلی، تعرفهٔ نمایشی، ساعت، امکانات و دسته است. فایل‌ها از S3 یا دیتابیس نمی‌خوانند، نشست صادر نمی‌کنند و تمام writeها405 هستند. نام‌ها و تعرفه‌ها دادهٔ واقعی بازار نیستند. این fixture اثبات انتشار کاتالوگ PH1، مجوز حساب یا معامله نیست.

[manifest و هندسه/تصاویر هر مورد](ph0-protected-reference-2026-10-18.json). همهٔ۱۲ مورد: یک main، بدون سرریز افقی، بدون کلاس Luma روی پوستهٔ باشگاه، anchor تصویر مطابق شناسه و همهٔ۸ تصویر با naturalWidth مثبت داشتند. در هر capture ابعاد viewport دقیق و scrollY صفر بررسی شد. متن metadata فارسی است؛ labels و جهت و عدد/تاریخ از زبان اپ پیروی می‌کنند.

captureهای اولیهٔ دارای scrollY غیرصفر رد و در manifest حفظ شدند؛ تصویر نامعتبر به‌عنوان شاهد قبول نشد. کلیدهای Home در این مسیر اسکرول را به صفر تثبیت نکردند. برای بارگذاری همهٔ تصاویر lazy و بازنشانی طبیعی محدودهٔ اسکرول، viewport موقتاً بلند و سپس به ارتفاع۸۴۴ برگردانده شد؛ هیچ CSS یا DOM محصول دست‌کاری نشد. فقط پس از تأیید ارتفاع۸۴۴ و scrollY=0 تصویر مرجع نوشته شد. viewport موقت در ابزار تا۴۰۹۶ محدود بود.

دو تصویر تمام‌صفحهٔ فارسی/تیره/۳۹۰ و انگلیسی/روشن/۳۶۰ با ابزار تصویر بازبینی شدند. تصویر تمام‌صفحه محل عناصر fixed/sticky را مطابق viewport نگه می‌دارد و ممکن است بخشی از متن پشت آن‌ها بیفتد؛ مقایسهٔ تک‌بخش‌ها و تعامل واقعی همچنان لازم است. [نمای ابتدای صفحه](baselines/ph0-2026-10-18/club-detail-fa-dark-390-top.jpg) نیز جدا ذخیره شد.

۲۶ آزمون HTTP fixture و lint مرتبط پاس‌اند. محافظ۵۹ فایل پیش و پس از capture پاس است؛ baseline هش تغییر نکرد. برای تغییر فقط fixture، build محصول تکرار نشد؛ preview از build موجود `hGEDvIN1Tt2ITD_KapQvn` استفاده کرد. این گزارش typecheck/build تازهٔ fixture را ادعا نمی‌کند. زبان/ظاهر به فارسی/تیره برگشتند، viewport reset و تب و دو فرایند این مرحله عادی بسته شدند؛ Docker و دستگاه اجرا نشدند.

reference کارت‌های portrait/compact/landscape، CoachCard و portrait آن، featured، شعبه و نقشه و مقایسهٔ نهایی پس از اصلاح حرکت بازند. این مرحله P0-01 یا PH0 را نمی‌بندد.
