# بررسی فلوها و حالت‌های مرزی — ۲۷ اکتبر ۲۰۲۶

بررسی روی نسخهٔ فعلی مخزن و دامنهٔ نسخهٔ اول انجام شد. مرجع دامنه، [سند فضاهای نسخهٔ اول](../product/v1-workspaces-2026-10-27.fa.md) است. قابلیت‌های منتقل‌شده به نسخهٔ دوم دوباره فعال نشده‌اند؛ تست سرویس‌های قدیمی برای حفظ سازگاری داده و تعهدهای قبلی اجرا شده است.

نتیجه: باگ‌های یافت‌شده اصلاح شدند؛ **۷۷۴ تست خودکار**، بررسی نوع‌ها و lint موفق‌اند. ساخت وب اپ ورزشکار، پنل مجموعه، پنل ادمین، وب‌سایت و ساخت API موفق است. این نتیجه به معنای اثبات نبود هر نوع باگ یا اجرای دستی تک‌تک ۱۱۰ صفحه نیست؛ پوشش خودکار، بازبینی کد و بررسی مرورگری در ادامه جدا شده‌اند.

## نتایج قابل تکرار

### تست‌های معمول مخزن

دستور ریشه:

```sh
pnpm exec turbo run test check-types lint --concurrency=2 --cache=local:
```

۲۴ کار موفق؛ اجرای تست‌ها شامل ۲۴۰ تست اپ، ۱۵۴ تست واحد API، ۵۶ تست کلاینت API و ۲ تست ترجمه است: **۴۵۲ تست**. هفت تست جدید، مقدار اعشاری، ظرفیت گروه، تفکیک گروه دوره، جلسات جایگزین و fallback بدون provider را پوشش می‌دهند. قبل از اصلاح، تست‌های بازتولید عدد اعشاری و تداخل گروه‌های دوره شکست خوردند؛ پس از اصلاح موفق شدند.

آزمون‌های Jest با تنظیم متناظر در `apps/api/test/jest*.json` و آزمون‌های Node با فایل‌های `*.integration.test.ts` اجرا شدند. همه از پایگاه جداگانه با پسوند `_test` استفاده کردند. آزمون‌های وابسته به جست‌وجوی فارسی و فایل در اجرای نهایی روی پایگاه تازهٔ UTF-8 اجرا شدند.

در آماده‌سازی محیط، encoding اولیهٔ پایگاه و رفتار دسترسی ناشناس شبیه‌ساز فایل باعث شکست‌هایی شدند. این موارد با پایگاه UTF-8 و SeaweedFS برطرف و مجموعه‌های مربوط کامل دوباره اجرا شدند؛ تست یا انتظار امنیتی برای سبزشدن حذف نشد.

### ساخت و کنترل‌های تکمیلی

- ساخت production وب اپ ورزشکار، بیزینس و ادمین با `GYM_QA_WEB=true API_URL=http://127.0.0.1:7088 pnpm exec next build --webpack` موفق شد؛ اپ و ادمین از خروجی ساخته‌شده نیز در مرورگر اجرا شدند.
- ساخت وب‌سایت با Webpack و ساخت Nest API موفق شد.
- `check-protected-design`: هر ۵۹ فایل طراحی حفاظت‌شده مطابق baseline است.
- `check-workspace-dependencies`: وابستگی مستقیم ۱۲ workspace در ۱۲۱۷ فایل بررسی شد.
- `git diff --check` موفق است.
- برای آزمون بازیابی render، یک صفحهٔ موقت با خطای عمدی ساخته شد؛ fallback و دکمهٔ تلاش دوباره در مرورگر کار کردند. صفحهٔ موقت بعد از بررسی حذف شد و در خروجی نهایی نیست.

گزارش‌های اجرای این نوبت و تصاویر در `.artifacts/flow-audit-2026-10-27/` هستند؛ این مسیر محلی و خارج از Git است. تصاویر شامل `render-recovery.png`، `receptionist-services.png`، `accountant-denied.png`، `manager-services.png`، `dependent-unavailable.png` و `admin-empty-review.png` است. سرویس‌های موقت متوقف و پایگاه داده و ابزار ذخیره‌سازی موقت پاک شدند.

## محدودیت‌های تأیید

- ساخت native اجرا شد اما محافظ موجود پروژه پیش از شروع، به دلیل کمبود فضای آزاد متوقفش کرد: ۲٫۹ گیگابایت موجود در برابر ۵ گیگابایت لازم. خروجی native جدید یا آزمون روی Android/iOS واقعی تأیید نشده است.
- پرداخت و استرداد واقعی، پیامک واقعی، دریافت push روی گوشی و دوربین/اسکن روی سخت‌افزار واقعی انجام نشدند؛ پوشش فعلی قراردادها و سناریوهای آزمایشی است.
- تست مرورگری منتخب است؛ پوشش همهٔ نقش‌ها ترکیبی از تست خودکار، بررسی کد و سناریوهای ثبت‌شده است. تضمین مطلق «هیچ باگی وجود ندارد» از این بررسی قابل استنتاج نیست.
- این تغییرات فقط در workspace انجام شده‌اند؛ انتشار آنلاین یا commit/push انجام نشده است. تنظیمات محلی ازپیش‌موجود `.vscode/` دست‌نخورده ماند.
