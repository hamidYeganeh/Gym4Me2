## Changes

- Persistent navigation surrounds all authenticated business/admin routes,
  including standalone calendar, finance, training and messaging screens.
  Desktop uses a scrollable grouped sidebar; mobile uses an accessible Sheet
  with a pinned account footer. Navigation is outside page transitions and
  links do not eagerly prefetch the entire workspace.
- One typed registry defines navigation, page titles and active nested routes.
  Tests verify unique links, actual route files and prefix boundaries.
- Filter Sheets keep their result/clear controls outside the scrolling body.
  Valid form submissions, nested selectors and overlay history remain supported.
- Discovery has a quieter results toolbar, distinct no-catalog/no-match states
  and a working clear-filters recovery action. Club/branch cards are preserved.
- Settings groups appearance, language and notifications under preferences.
- Finance always shows the selected organization, branch and date scope.
  Changing scope resets pagination. Mobile metrics use two columns and a
  full-width balance card; coach finance reserves space for bottom navigation.
- Shared empty states and Persian numeric formatting are consistent.

## Browser verification

Isolated `GYM_QA_WEB=true` fixtures, with no API/database process or production
write. The QA-only canvas expands panel previews to their real viewport width.

Thirty screen families were inspected at 360 px in Persian/dark: business and
admin shells, discovery, settings, profile/edit, home, services/detail,
bookings/detail, memberships, orders, checkout, payment, messages,
notifications/preferences, coaching, training/builder/workout, coach finance,
admin/coach analytics, privacy, cards, club, gallery and map.

Additional coverage: discovery empty/error, bookings error, guest settings;
English/light settings, discovery, booking, checkout and workspace shells;
390 px mobile, 768 px tablet and 1440 px desktop. These are representative
screen-family checks, not every route/role/state/language/theme permutation.
The final geometry observations had no document overflow or busy state.

Interaction checks:

- Mobile menu focuses its first navigation link, Escape closes it and restores
  focus to the trigger; all workspace routes remain reachable by scrolling.
- Financial branch selection opens a nested Sheet. Selecting a branch and
  applying filters closes the parent and updates the visible scope.
- Filter action is a visible 44 px target at the bottom of a 390 × 844 viewport.
- Empty discovery search shows the no-match recovery action; clearing it restores
  the no-catalog state and clears the input.
- Theme/language changes render correctly using the actual settings controls.
- Reduced-motion emulation disables the new navigation transition. Existing
  approved 120/220/200 ms motion values remain unchanged.

Evidence: [baseline screenshots and layout observations](baselines/ux-polish-2026-10-23/).
Fixtures contain synthetic data only. Physical devices and every browser engine
were not tested during this UI pass.
