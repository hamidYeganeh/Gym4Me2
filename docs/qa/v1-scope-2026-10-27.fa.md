## رابط و حدود بررسی

در بررسی اولیهٔ مرورگر، صفحهٔ خدمات پنج نوع خرید اصلی و چهار مقصد «خانه، باشگاه‌ها، رزروها، عضویت‌ها» را نشان داد؛ ورودی بازی و تقویم دنبال‌شده وجود نداشت. بارگذاری دادهٔ آن مشاهده به خطای محیط آزمون رسید. پس از راه‌اندازی دوباره، برگهٔ خطای اتصال مرورگر توسط سیاست URL ابزار مسدود شد؛ بررسی تعاملی ورود/خرید و همهٔ حالت‌های احرازشدهٔ رابط در این نوبت تأیید نشده‌اند.

اجرای هم‌زمان بررسی‌های پایانی باعث کمبود فضای دیسک، توقف PostgreSQL موقت و شکست نخست ساخت API شد. اجرای بعدی API با سقف heap بیش از حد کوچک نیز به کمبود حافظه رسید. ساخت API سپس به‌تنهایی با heap برابر 1536 MiB موفق شد؛ ساخت بیزینس نیز موفق است. شکست‌های اولیه در نتایج موفق بالا شمرده نشده‌اند. PostgreSQL اختصاصی پس از آزاد شدن منابع بازیابی شد.

خروجی جدید native، نصب گوشی، ساخت production ادمین، CI راه‌دور، push و استقرار آنلاین جزو شواهد این نوبت نیستند. قرارداد لینک Android/Apple آزموده شده است. کاربر حذف کد از `main` را خواسته؛ این تحویل به‌خودی‌خود انتشار آنلاین نیست.

## حفظ سابقه

جدول‌ها و migrationهای تاریخی باقی مانده‌اند. خروجی و حذف حساب، دفتر مالی و مسیر استرداد سفارش‌های قبلی حفظ شده‌اند. کد عرضهٔ تازهٔ بازی، اعتبار، تغذیه، پیشنهاد تطبیقی و دنبال‌کردن تقویم از مسیرهای فعال حذف شده است. تنها منطق مالی لازم برای تعهدهای قبلی در `LegacyGroupReconciliationService` و دفتر استرداد اعتبار باقی است.
