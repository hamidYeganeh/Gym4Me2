# دعوت‌های ورزشی در وب — ۱۸ اکتبر ۲۰۲۶

ادامهٔ رابط T069 و PH0/PH2 با دستور ادامهٔ فقط وب. Docker، PostgreSQL، S3، staging و دستگاه اجرا یا بازراه‌اندازی نشدند. دادهٔ مرورگر فقط DTO مصنوعی است؛ این برش پذیرش دعوت واقعی یا فاز نیست.

## تغییر

دعوت‌ها از community جدا و به LumaLoadMore موجود متصل شدند. خطای موقتِ ادامهٔ فهرست، دعوت‌های قبلی را نگه می‌دارد و Retry همان cursor را درخواست می‌کند. خطاهای ورود/دسترسی از این استثنا عبور نمی‌کنند. دکمه‌های پذیرش و رد از Button موجود با دو variant متمایز استفاده می‌کنند؛ خدمت ناموجود پذیرش فعال ندارد و رد همچنان ممکن است. حالت accepted فقط برای خدمت موجود، مسیر مشاهده/ثبت‌نام دارد. متن «پذیرش دعوت به‌تنهایی رزرو نیست» حفظ شد.

guard ارسال تکراری به پاسخ اضافه شد؛ revision و کلید idempotency موجود حفظ شدند. focus پس از موفقیت پاسخ فقط در سطح فعال و در صورت حفظ مالکیت focus برمی‌گردد؛ callback موفق واقعی در این برش قابل پذیرش نبود.

LumaLoadMore اکنون انتخاب بعدی کاربر را حفظ و سطح مبدأ را بررسی می‌کند؛ callback قدیمی نمی‌تواند ردیف صفحهٔ دیگری را فوکوس کند. در خطا، focus به دکمهٔ بازفعال‌شده برمی‌گردد. اگر ادامهٔ موفق مورد تازه‌ای نداشته باشد، دعوت‌ها شناسهٔ وضعیت فهرست را به‌عنوان مقصد focus می‌دهند. خطای غیرمنتظرهٔ Promise نیز پیام قابل مشاهده دارد. قرارداد مصرف‌کنندگان قبلیِ helper تغییر نکرد.

## شاهد

[ماتریس، نتیجهٔ فلوها، hash منابع و build](invitations-web-matrix-2026-10-18.json).

- ۱۹ آزمون HTTP فقط‌خواندنی با heap۱۲۸ و concurrency=1 پاس‌اند: cursor واقعیِ پاسخ، ۲۵+۴ مورد بدون تکرار/جاافتادگی، cursor نامعتبر، خطای ادامه، فهرست خالی و پایان خالی. صفحهٔ سرور موجود ۲۵ مورد دارد؛ fixture همین اندازه را حفظ می‌کند.
- lint فایل‌های مرتبط، کاتالوگ متن، قالب، `git diff --check` و محافظ ۵۹ فایل پاس‌اند. build نهایی ورزشکار با یک worker و heap۵۱۲ موفق شد: compile۱۰٫۳ و TypeScript۵٫۱ ثانیه،۶۴ صفحه. preview و fixture هنگام build خاموش بودند.
- ۱۲ مورد زبان/تم/عرض۳۶۰،۳۹۰،۴۳۰: یک main فعال، بدون سرریز، ۲۵ شناسهٔ یکتا، پذیرش/رد، ناموجود، accepted، declined و cancelled بررسی شدند؛ دکمه‌های پاسخ حداقل۴۴×۴۴ بودند. ماتریس پیش از تکمیل fallback فوکوس Retry/پایان خالی ثبت شد؛ ظاهر این کنترل‌ها تغییر نکرد و فارسی/تیره/۳۹۰ روی build نهایی دوباره بررسی شد.
- Enter روی «دعوت‌های بیشتر»، فوکوس را به اولین دعوت جدید، شماره۲۶، برد. پس از انتخاب لینک دیگری در زمان انتظار، فوکوس روی کشف ماند؛ این حالت روی build نهایی بازآزمایی شد. دوبار کلیک،۲۹ شناسهٔ یکتا و بدون دکمهٔ ادامه به‌جا گذاشت؛ تعداد دقیق درخواست‌های شبکه اندازه‌گیری نشد.
- خروج به خانه هنگام انتظار، یک main فعال و صفر دعوت فعال داشت؛ callback فوکوس دعوت را پس نگرفت. این مشاهدهٔ پایدار پس از ناوبری است و ضبط تمام frameهای حرکت نیست.
- شکست ادامه ابتدا۲۵ دعوت را حفظ می‌کرد ولی focus روی BODY می‌افتاد. پس از اصلاح نهایی، Retry فوکوس داشت؛ با بازیابی endpoint همان cursor موفق شد، هشدار حذف و دعوت۲۶ فوکوس شد. ادامهٔ موفقِ خالی نیز با۲۵ مورد و بدون More، focus را روی وضعیت فهرست گذاشت.
- فهرست خالیِ موفق، صفر مورد و پیام خالی، بدون هشدار یا More داشت. دریافت401 برای ادامهٔ فهرستِ دارای داده، همهٔ دعوت‌های کش‌شده را مخفی و لینک ورود با مقصد `/invitations/sports` نشان داد.
- لینک دعوت accepted به جزئیات خدمت رفت و Back به دعوت‌ها برگشت. پاسخ آزمایشی با405 رد شد؛ وضعیت invited و فهرست باقی ماندند و خطا دیده شد. هیچ پاسخ موفق، رزرو یا تخصیص ظرفیت شبیه‌سازی نشد.

fixture چهار حالت invitation دارد و فقط GET/HEAD می‌خواند. همهٔ درخواست‌های تغییردهنده405، profile/auth همچنان401 و هیچ cookie یا نشست صادر نمی‌شود. سناریوهای خطا/بازیابی با تعویض فقط همین فرایند loopback اجرا شدند؛ بک‌اند واقعی درگیر نبود.

[تصویر نهایی فارسی/تیره/۳۹۰](screenshots/invitations-web-2026-10-18/invitations-fa-dark-390.jpg) با ابعاد واقعی۳۹۰×۸۴۴ بررسی شد. زبان/ظاهر به فارسی/تیرهٔ شروع برگشتند، viewport reset و همهٔ تب‌ها و فرایندهای این اجرا عادی بسته شدند.

## بازمانده‌ها

پاسخ واقعی، تعارض revision، replay سرور، اثر ظرفیت، focus پس از پاسخ موفق،403 و جداسازی واقعی حساب‌ها هنوز پذیرش نشده‌اند. helper مشترک در گفتگو/اعلان نیز مصرف می‌شود؛ رگرسیون داده‌دار آن دو در این برش تکرار نشد. صفحه‌خوان، zoom، دستگاه، baseline کامل بصری و زمان‌بندی/همهٔ frameهای حرکت بازند. هیچ کارت club/coach، صفحهٔ جزئیات باشگاه، Kit، CSS عمومی، API سرور یا migration تغییر نکرد. T069 و دروازه‌های فازها باز می‌مانند.
