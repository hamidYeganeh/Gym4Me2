Included 7793 foods with all four macros in supported ranges. Values are per 100 g and rounded to two decimal places. Missing values are excluded, never replaced with zero. Persian labels are original translations for selected common foods; original source descriptions are preserved. SR Legacy is a historical composition dataset, not current brand labels.
